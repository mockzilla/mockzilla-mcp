# Connected accounts

**Connected Accounts** is a tab in Settings. It lists the ways you can sign in. Add one or remove one here.

(Image: The Connected Accounts tab: a connected GitHub account, Google not connected, and an organization offering single sign-on.)

*The Connected Accounts tab*

**Connect** sends you to the provider and back. **Disconnect** removes the link.

A Google or GitHub account can only be linked to one Mockzilla account. If it is already linked to another one, the connection is refused. Sign in to that account instead, or disconnect it there first.

## Google

Sign-in only. Connect it, then use **Continue with Google** on the sign-in page.

## GitHub

GitHub is a sign-in method. It also gives you access to your repository simulations.

A repository deploys a simulation when its workflow runs, with or without an account behind it. Connect GitHub and those simulations appear in your list.

You see the simulations from repositories you can access. Your role on each one follows your permission on the repository:

- **Admin** makes you an owner.
- **Write** makes you an editor.
- **Read** makes you a viewer.

Disconnect and you lose that access. The simulations keep running. Connect again and you get it back.

See Simulations from GitHub (topic `simulations/github-simulations`).

## Your last way in

Disconnecting your only sign-in method signs you out. The app asks you to confirm first.

You can still get back in. Use **Forgot password?** on the sign-in page. The link we email sets a password for the account.

To avoid that, set a password first, then disconnect.

See Preferences and password (topic `settings/preferences-and-password`).

Organizations that sign their members in through their own provider get a row here too.

See Set up single sign-on (topic `settings/single-sign-on`).
